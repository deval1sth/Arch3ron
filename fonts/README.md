# Fonts

- **Bricolage Grotesque** (headings): `bricolage.woff`, an instance of the variable font at width 100, optical size 32, weights 500 to 800, subset to the characters Archeron shows.
- **Atkinson Hyperlegible Next** (body): `atkinson-400.woff`, `atkinson-700.woff`, `atkinson-italic.woff`, static cuts subset the same way. The zero is redrawn without its slash so numbers read like ordinary print.

Both are under the SIL Open Font License 1.1 (`OFL-Bricolage.txt`, `OFL-Atkinson.txt`). Neither declares a Reserved Font Name.
