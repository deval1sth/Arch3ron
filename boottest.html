Boot check

Starts the app with every kind of unfinished state (each practice paper, each PPP paper, generated papers, a revision session, a guide to resume) and checks that no part of the save is left out while app.js is still loading. That is the bug that hid Runo's whole save on 8 Nov 2026. Run it before pushing any change to app.js, plus.js, study.js, me.js or a script that normalize() calls.

Local server only. It uses its own test profile and puts this browser's Archeron storage back when it ends. Agents: read window.BOOT_RESULT.
